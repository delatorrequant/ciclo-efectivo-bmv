# ciclo-efectivo-bmv
Objetivo: calcular cuántos días tarda cada una de 5 empresas de la BMV en recuperar el dinero que mete a su operación, y comparar el resultado con lo que predije antes de ver los datos.
## Emrpesas:
Walmex/Bimbo/Cemex/Alsea/Gruma
## Datos:
Reportes anuales 2025 de cada empresa (estados financieros consolidados). Cada número lleva su fuente: reporte y página.
## Formulas: 
- Días de cobro = cuentas por cobrar ÷ ventas × 365
- Días de inventario = inventarios ÷ costo de ventas × 365
- Días de pago = proveedores ÷ costo de ventas × 365
- Ciclo = días de inventario + días de cobro − días de pago
## Como se considera que fallo: 
Si al 1 de noviembre de 2026 no hay una tabla de las 5 empresas con la fuente de cada número, el proyecto falló, y este README lo va a decir.
